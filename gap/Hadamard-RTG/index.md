The eye-J.txt file is read by Hadamard-RTG, to define some required functions.  
The [sample input](sample input/index.md) folder includes the real symmetric Hadamard matrices of orders 4, 8, 16, and 20.  
Graphs produced with these inputs are found in the [matrices](../../matrices/index.md) folder.

  +You need this: [eye-J.txt](eye-J.txt)
  +to run this: [Hadamard-RTG.g](Hadamard-RTG.g)
