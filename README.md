# srd-rtg
This site houses GAP code and text files for the construction and analysis of strongly regular graphs in the family 
$(4m^2, 2m^2\pm m, m^2\pm m, m^2\pm m).$  These are representative of *regular twographs* and therefore have descendant strongly regular graphs in the family 
$(4m^2-1, 2m^2, m^2, m^2)$.  
My interest in these is: the descendants are candidates for *strongly regular decompositions*.  
A preprint detailing this work is [here](doc/sankey-srd-II.pdf).
